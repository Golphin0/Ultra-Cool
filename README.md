# Ultra-Cool
A simple tool that creates some useful links (Such as God mode) with a library of icons  
# Build
simply but the build.ps1, base.ps1 and base64.txt into one folder, and run the build.ps1. It will put the vars in base64.txt into base.ps1 and output a final UltraCool.ps1.  
You can also simply run base.ps1 with base64.txt in the same folder.
